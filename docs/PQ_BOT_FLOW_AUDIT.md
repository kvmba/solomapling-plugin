# PQ Bot 全流程核对

范围：`PqBotSpawner` / Bot 类型注册中已有实现的 16 种玩法（含玩具塔；嘉年华两版、玛加提亚两边各按一种玩法计）。对照插件、GMS083 的 NPC／传送门／事件脚本及地图数据。没有 Bot 类型的宿主活动不算已支持。

## 玩具塔 101：基准流程

| 流程 | Bot 做什么 | 谁说话、谁确认 |
| --- | --- | --- |
| 招募、入场 | 在入口 NPC 附近活动；未入队时喊组，收到邀请后入队并停止招募。玩家开本，Bot 由事件带入。 | 未组队的 Bot 各自按间隔喊组；开场、工作、过门有概率短句，不是任务指令。 |
| 1：塔内鼠群 | 击杀、拾取通行证；收集结束到气球 NPC 交付点集合，把道具放成队长专属拾取堆。 | Bot 可报首关分工、实际交付者报掉落；队长拾取、交证并开门。 |
| 2：塔箱与陷阱 | 分箱打，塔内箱子清空后才触发陷阱箱。陷阱房继续打箱、拾证，从自己的出口回塔；主房等队长交证。 | 不把子房里的队长误判为进入下一关；交付者报交证点，队长确认。 |
| 3：召怪箱 | 打开木箱、击杀召出的怪、拾证，随后回 NPC 集合交付。 | 实际交付者报掉落，队长交证。 |
| 4：暗房 | 各 Bot 认领房间，杀怪、拾证、走回主房交付；关卡已清时退出子房追队。 | NPC 判定后由同房代表报殿后；玩家队长先走。 |
| 5：职业门 | 按职业能力认领：高门需要瞬移，守卫房需要隐身或伪装；不可杀的守卫不当作普通怪。没合格分工的 Bot 在主房待命。 | 实际交付者报掉落；队长交证，不要求没有相应技能的 Bot 硬闯。 |
| 6：塔梯 | 走真正能向上推进的传送门；队长到顶也不替落后的 Bot 跳级。 | 有清关或过门短句，但爬梯由各角色自己完成。 |
| 7：召唤石箱 | 处理高台怪，让掉落留在触发区，由石箱召出洛姆巴德；再打怪、拾取通行证并送到 NPC。 | Bot 不捡触发石，不代替队长判定；需要交证时报告交付。 |
| 8：五人站箱 | 分担九选五的站位，额外 Bot 在气球旁待命；失败后换组合。 | 同队同地图实例中，符合工作条件的最高等级 Bot 报本轮；同级取较小角色 ID。由玩家补位、队长与气球对话判定。 |
| 9：首领 | 在可达时帮助打召唤水晶，攻击阿丽莎乐；队长交战利品。 | 清关事件当场发一次殿后台词，不等队长出图；最终关清除不等于离开副本。 |
| 奖励和出场 | 宿主将全队传到 `922011000` 打奖励箱；Bot 打箱但不捡奖励掉落。到 `922011100` 走到出口 NPC 旁停留，不抢玩家奖励，最后回大厅。 | 不再做普通关卡喊话；玩家还在同局结算时 Bot 不提前回城。 |

## 其余玩法

除特别注明之外，开场均由玩家在对应 NPC 开本，公共 Bot 行为负责应邀、入场，以及通过关卡真实门追队。表中的「集合」指走到任务 NPC 或出口旁，不是站在原地等计时，也不是跳过房间回城。

| 玩法 | 开始与进行中 | 完成、奖励、离场 |
| --- | --- | --- |
| 废弃都市 | 1：Bot 亲自找克洛托接个人题，按配额收券、换通行证再交队长；个人进度由当事 Bot 报。2–4：绳／台／桶分工站位，同房一名 Bot 报 **本轮实际需要玩家补的点**。5：杀怪并拾证，在克洛托旁交队长。 | `103000804` 清关后先在克洛托处等；有队友进入 `103000805` 时 Bot 自己按 NPC 奖励流程进入，没有假定存在物理传送门。陪队友打奖励怪；经内拉去 `103000890` 等队友，再出副本。 |
| 射手村 | 先打叶、找种子、按颜色种花；满月后护兔。一个携年糕的 Bot 做交付，其余继续防守；玩家向老虎提交。 | 全队到 `910010100` 在兔子 NPC 旁结算；队长可带队去猪村 `910010200`，Bot 在场帮打，随后经 Tommy 或宿主计时去 `910010400`。失败时也在 `910010300` 出口陪队友。 |
| 通天塔 | 单独的状态机；分云箱、搬云、等侍从开路；散步道打怪、清仓、找当天唱片、站封印台、走休息室子房、拨杆、点塔痕、打精灵爸爸、放最后部件。 | 封印台也用同房代表报站位。救出女神后跟队去监狱或隐藏房、帮开箱／打怪；在 `920011100` 打宝箱，或到 `920011300` 陪队领取。队长先走时，跟仍在同局结算的玩家。OPQ 已接入同一个清关殿后事件。 |
| 海盗 | 入口打怪，清箱模式才打门槛箱；奖章房三轮分别按当前颜色收集、交付。航道依规则清怪或打箱放怪，船长房帮打。奖励升级支路由玩家选择。 | 船长倒下后去武扬旁等队长；宿主全队移动到 `925100600` 后陪队友结算，不再秒回百草堂。失败出口 `925100700` 也等待同队玩家。 |
| 阿莫利亚 | 镜片交付、两关站位、雕像碎片、存活关、首领战利品；站位由同房代表每轮报空位，玩家队长判定。 | 少数队伍先做夫妻奖励 `670010750`，Bot 打箱／打怪，走真实传送门；常规奖励 `670010800` 帮打箱，不把奖励当首领交付。在出口 `670011000` 集合再回大厅。 |
| 玛加提亚 A/Z | 调查室由玩家检查线索；Bot 清怪、收试剂和喂烧杯、开资料门、交文件。同房一名 Bot 报跳台组合；Bot 经脚本占一个空槽，走自己的十级跳台，随后协助首领与护送战。 | 用事件的真正清除标记判断，不把决定首领种类的 `yuletePassed` 当成通关。走 Romeo／Juliet 的结算对话及各边 `…500`、`…600`，等玩家领奖后回各自招募地图。 |
| 毒雾森林 | 入口集合；清怪，拾毒液喂泉水、用稀释毒液消刺；逐格走迷宫的脚本门，到 NPC 所在格才对话，未传送时重试；玩家削弱污染怪，一名 Bot 用净化石捕捉、把弹珠留给队长确认。开箱得紫石、祭坛召首领并帮打。 | 首领死后等人，队长走 `out00` 带队；到 `930000800` 时在出口集合，玩家离场后再走奖励出口。 |
| 扎昆前置 | 打矿洞箱、拾火之矿，回主洞 Adobis 交队长。队长确认是否同时交 30 张文件；不把个人跳关当 Bot 任务。 | 宿主出口与招募点同为 `211042300`，没有额外的队伍奖励房；按 NPC 流程结束，不凭空造奖励阶段。 |
| 黑龙前置 | 各洞击杀拿钥匙并交队长，等脚本开洞；队长交五把钥匙，选明暗房，Bot 帮刷两种最终钥匙及交付。 | 宿主把队伍放到 `240050400` 后留在 NPC 旁。后续进入黑龙远征是另一个玩法，不自动替玩家报名。 |
| 帕普拉图斯 | 由玩家放召唤物；Bot 打球、钟和本体。此前等待召唤，不能用空场误报通关。 | 真实完成后到墓碑 NPC 旁，仍有同队真实玩家就不离开；队长中途退场仍按放弃处理。 |
| 武陵道场 | 队长开组队道场，Bot 打各层首领、走晋级门，随队到休息层。 | 退出 `925020002` 与通关 `925020003` 均在出口等同队玩家，不在落图时马上回道场大厅。 |
| Boss Rush | 各房协助战斗，清怪后在传送门附近等待队长；每五关去脚本对应的领奖／退出点。 | `970030001–970030010` 是实际奖励房。Bot 到奖励 NPC 附近等待自己队伍，不当作还有一轮要打。 |
| 奈特金字塔 | 跟计时进波次；见禁打的幼雪人时按保守规则停攻，不把禁怪计作击杀目标。 | 队伍结束后在杜阿特结算地图 `926010001`／`926020001` 留场。玩家个人换入额外宝物图不强行跟随。 |
| 阿里安特竞技场 | 不收普通组队邀请；按远征队报名、等比赛、用场内道具捕蝎。 | 在王室 `980010010` 按同一场竞技对象等真实对手读分和领奖，忽略同图其他比赛的人。 |
| 怪物嘉年华 I/II | 大厅应邀，随己方队伍入场；打自己一侧的怪、捡竞技补给、用 CP 召怪或施加减益。 | 原有胜负房停留已符合标准：同侧有真实玩家时等他们读分；全 Bot 对手队只短暂停留，不等其他队。 |

规则分层：普通招募和氛围聊天不代替关键进度提示；站位／殿后由同房代表报，交付仍由真的做了交付的角色报。单关完成后，按脚本的门、交付点、NPC 传送或团队传送推进。结算完成与玩家离场是两个信号；不因最终关旗标刚翻转就提前回城。
