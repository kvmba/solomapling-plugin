# 挂机 / 游走 / 城镇区域 占比梳理

> 口径：从 `docs/BOT_SPAWN_MAPS.md` 的全量 2606 中**剔除特殊 bot**
> （自由市场全部：入口 45 / 商人 45 / 房间内 bot 店 302 / 雇佣商人 241；
> 以及 21 点 23 / OPQ 12 / Gacha 3 / 掉落游戏 5 / 游戏区 Host 2 / 教学 1 / ScrollBot 改型 10）
> → **剩余 1917 个**为本文统计对象。
>
> 判定标准（按你的定义）：**只有一出生就游走的类型算游走 bot**；
> 挂机 → 偶尔搬家 → 再挂机的，仍是挂机 bot。

## 一、类型归类依据

| 归类 | 包含 | 行为依据 |
|---|---|---|
| **挂机** | 城镇驻点 SOCIAL_BOT 442、射手村 filler 125、射手村 social 9、宠物公园 Social 14 | `SocialBot` 站定持有个 ledge 占位（`TownStation.claimSpot`）；每 3–8 分钟 `maybeRelocate()` 漂到新点**再站定**；每 4–11 分钟 `maybeStroll()` 去邻图逛 30–90 秒，但 **65% 概率返回原图**（`ONE_WAY_STROLL_CHANCE=0.35`）。本质仍是驻守。 |
| **游走** | 城镇漫游 TOWN_WANDERER_BOT 255、射手村 HENESYS_BOT 60 | `TownWandererBot` / `HenesysBot` 的 FSM 一启动就进 `WANDER` / `CHANGE_MAP`：持续巡游 ledge，冷却到了就换子图（90 秒 / 10% 每 tick）。出生即在走。 |
| **跳 JQ** | 宠物公园 HENESYS_JQ_BOT 15 | `HenesysJQBot` 一出生就 `NAVIGATE_TO_JQ → ATTEMPT_JQ → RECOVER → REST` 循环跑跳跳任务，不是观光漫游。单列。 |
| **练级** | TRAINING_BOT 997 | 出生在城镇/枢纽 hub，随后自行发现猎场并散开。 |

## 七、结论要点

1. **挂机 590 : 游走 315 ≈ 65 : 35**，这个比例在所有城镇里基本一致（每个城镇都按"驻点数 + wanderers 数"配置，结构相同）。
2. **射手村是唯一失衡的大城**：常驻 247，占全部常驻人口 26.8%，且不受 YAML 控制。
3. **游走 bot 只存在于两类地方**：46 个 `town_presence` 城镇（wanderers 255）和射手村（HenesysBot 60）。
   纯练级 hub（如玩具塔 1 层、通天塔门口、蚂蚁广场）只有练级 bot，**没有任何常驻人口**。
4. **彩虹岛、黄金海滩只有练级 bot**，无常驻人口——符合"没人住，练完就走"的设计。
5. **诺特勒斯 / 玛加提亚 / 新叶城 / 上海外滩** 有常驻但无练级（船舱、室内、无猎场），是纯生活区。

## 八、已修复：`m4/m5/m6_social` 批次从未赋型

`EnvironmentManager.spawnHenesysBotsBatch` 曾把三批射手村 social bot 建进局部变量 `s1/s2/s3` 后丢弃。
这些角色**确实被创建了**（`m4_social.csv` 等录制文件存在，占位与限流配额都照常消耗），
但从未传给 `setAndStartBots`，因此 `CharacterStorage` 里没有对应的 `BotSM`：

- 没有任何 tick 驱动它 → 不说话、不做表情、不漂移、不换图；
- 所有 ambient 扫描用 `getBotById(...) != null` 过滤候选 → 它连"被改造成 ScrollBot"的资格都没有。

`scale=1.0` 下共 9 个（W1 social 5、W3 social 5、W5 social 4，各 `perSpot=1` × 3 条平台）。

已在 commit `b60d88a` 修复：三批改为直接 `setAndStartBots(..., SOCIAL_BOT)`，与射手村其它 filler 一致。
**创建数量不变**，同样的 9 个角色从静止空壳变为正常挂机 bot。

修复时特意**没有**先 `new ArrayList` 再 `addAll` 合并成一次调用——实测（JDK 21，3×10⁷ 次迭代，
5/7 轮取中位数）合并比三次直接调用慢约 34 ns/次：省下的只是 2 次方法调用加一个 varargs 数组，
却要多付一次 ArrayList 分配和三次数组复制。预分配容量同样没有帮助。
