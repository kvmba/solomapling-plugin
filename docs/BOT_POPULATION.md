## 五、已修正的一处冲突

**玩具城队列 `level_lo: 25` 低于区域门槛 30。**

生成不经过 `TrainingRegions.isAllowed`，25–29 级 bot 被放进玩具城后，
附近所有地图都被门槛过滤 → 找不到练级图 → **20 个 bot 永久空转**。

已改为 `level_lo: 30`。其余 15 个队列、7 个城镇全部一致（0 冲突）。

## 五之一、城镇分散到子图

一个城镇的驻点 bot 会分散到它**所有**合格子图，而不是挤在一张图上：
例如废弃都市分布在主街、夜市、广场；玩具城分布在主城、村落；
水下世界分布在三个甲板。这样人群填满整个城镇，而不是堆在一条街。

**不放 bot 的功能建筑**（访问一次就走，不该有人常驻）：
转职殿堂（弓手/战士/魔法师/飞侠）、整形医院、三号线工地、家族中心。
它们原来的名额已移到同大陆的真实街道，总量不变。

## 七、更正：日本 / 马来西亚 / 嵩山镇 可达

之前判定这三处"与主世界隔离"是**错的**，两个原因：

1. **只读了英文版脚本**。中文版 `9000020`（导游妮妮）是北斗的独立实现，
   提供 **5 个目的地**：上海外滩 / 嵩山镇 / 驳船码头城 / 吉隆大都市 / 古代神社。
   英文版只有日本和马来西亚，且按所在地图决定目的地。
2. **万能传送（`9900001`）** 是玩家付费传送菜单（含 少林寺 `702000000`、
   品克缤 `270000100` 等）。

### 重要：万能传送不代表区域无等级要求

万能传送是**付费直连**，绕开了地理与等级限制。区域门槛仍以
**区域规则 + 该区域最低怪物等级** 为准，不参考万能传送。
